# Trademark note

Arfolio's code is open source under the [GNU AGPL v3](LICENSE). You are free to run, study, modify and fork it.

The **"Arfolio" name and logo are not licensed** for use as the name or brand of a fork or a modified
version. If you distribute your own version or run it as a service for others, please present it under your
own name so people do not confuse it with the original project.

Rebranding is built in. Set these environment variables and the interface, page titles, manifest and icons follow:

| Variable              | Purpose                          |
| --------------------- | -------------------------------- |
| `BRAND_NAME`          | Product name shown in the UI     |
| `BRAND_PRIMARY_COLOR` | Primary colour of the interface  |
| `BRAND_LOGO_URL`      | Replaces the logo mark in the UI |

Accurate references such as "forked from Arfolio" or "compatible with Arfolio" are always fine.
